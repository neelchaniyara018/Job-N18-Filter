Welcome — One-Time Setup
This app runs scraping entirely on Google's cloud via Google Apps Script — no Node.js, no installation needed. Complete this setup once, and you're done forever.
1
Open Google Apps Script
Go to script.google.com → Click New Project → Delete all existing code
2
Paste the Scraper Script
Open the file google_apps_script.gs from your project folder. Copy ALL the code and paste it into the Apps Script editor. Click Save (Ctrl+S).
3
Deploy as Web App
Click Deploy → New deployment → Select type Web App
Execute as: Me | Who has access: Anyone
Click Deploy → Authorize when prompted → Copy the URL
4
Paste Your Web App URL Below
Paste the URL that looks like:
https://script.google.com/macros/s/ABC.../exec
